# はじめかた — 上から順にやれば終わります

アカウントを作るところから、出店に持っていくPOPを印刷するところまでの手順です。
**上から順に**やってください。順番を入れ替えると後戻りします（クーポンを先に作らないと、あいさつメッセージに貼れません）。

所要時間の目安：**60〜90分**。途中で止めても大丈夫です。

> 画面の名前やボタンの位置は、LINE側の更新で少し変わることがあります。
> 見当たらないときは、似た名前のメニューを探してください。やることは変わりません。

---

## STEP 0｜先に手元に用意するもの（5分）

- [ ] メールアドレス（お店用。個人のものでも構いません）
- [ ] 携帯電話（SMSを受け取ります）
- [ ] このリポジトリの `line/out/` フォルダ（画像をアップロードします）
- [ ] **テスト用にもう1台のスマホ**（夫婦それぞれのLINEでOK。最後の確認に使います）

**まだ決まっていなくても進められます**（あとから直せます）：
公式サイトのURL、SquareストアのURL、価格。とりあえず空欄で作って、決まってから入れます。

---

## STEP 1｜アカウントを作る（10分）

1. [https://entry.line.biz/start/jp/](https://entry.line.biz/start/jp/) を開く
2. 「LINEアカウントで登録」または「メールアドレスで登録」を選ぶ
   - 普段使っているLINEアカウントで登録するのがいちばん簡単です
3. 認証コードがSMSで届くので入力

### 入力フォームに入れる内容

| 項目 | 入れるもの |
|---|---|
| アカウント名 | `お芋やとろり` |
| メールアドレス | お店用のもの |
| 会社・事業者名 | 屋号（`お芋やとろり`）または個人名 |
| 業種（大業種） | `飲食店・レストラン` |
| 業種（小業種） | `その他飲食店` |
| 運用目的 | `商品・サービスの情報発信` |
| 主な使い方 | `友だちとのコミュニケーション` |

> **アカウント名は、あとから変更すると7日間変更できなくなります。** `お芋やとろり` で確定してください。
> 認証済みアカウントになると、アカウント名は変更できなくなります。

4. 作成できたら [LINE公式アカウントマネージャー](https://manager.line.biz/) が開きます。ここが今後の作業場所です

### 料金プランを確認する

**設定 → 利用と請求 → 料金プラン** が **コミュニケーションプラン（無料）** になっていることを確認します。
最初から無料プランなので、**何も操作しないのが正解**です。有料プランへの案内が出ても、無視してください。

---

## STEP 2｜応答の設定をする（5分）

★ **最初にここをやってください。** 初期設定のままだと、AIが勝手に的外れな返事をしてしまいます。

**設定 → 応答設定**

| 項目 | 設定 | なぜ |
|---|---|---|
| チャット | **オン** | 夫婦2人で直接お返事できるようにします |
| あいさつメッセージ | **オン** | 友だち追加のときに自動で届きます |
| 応答メッセージ | **オン** | キーワードに自動で返します。**何回返しても無料です** |
| AI応答メッセージ | **オフ** | 見当違いの返事をされると信用を落とします |
| Webhook | **オフ** | 今回は使いません |

「応答時間」の設定は**しなくて構いません**（24時間、キーワードに自動応答する状態にします）。

---

## STEP 3｜プロフィール画像とカバー画像を入れる（10分）

**ホーム → プロフィール**

1. **背景画像（カバー画像）** に `line/out/cover.png` をアップロード
2. **プロフィール画像** に、いものすけの画像をアップロード
   - まだ画像ファイルがなければ、この STEP は飛ばして構いません。あとから入れられます
3. **ステータスメッセージ** に貼り付け：

```
低温でじっくり。時間だけがつくる甘さの焼き芋です。
```

4. **ボタン** は「トーク」を表示にする
5. 右上の **公開** を押す

> カバー画像の左下には、プロフィール写真の丸とアカウント名が重なります。
> `line/design/cover.html` はそこを空けて作ってあります。写真に差し替えるときも同じ場所は空けてください。

## STEP 4｜クーポンを作る（10分）

★ **あいさつメッセージより先に作ってください。** あとで貼り付けるからです。

**ホーム → クーポン → 作成**

### ① 友だち追加ありがとうクーポン（必須）

| 項目 | 入れるもの |
|---|---|
| クーポン名 | `友だち追加ありがとうクーポン` |
| 有効期限 | 今日から1年後まで（※お客さま個人の期限は下の「利用可能回数」で効きます） |
| 写真 | なくてOK（あとで焼き芋の写真に差し替えると効果が上がります） |
| クーポンコード | 使用しない |
| 利用可能回数 | **1回のみ** |
| 抽選 | **抽選を使用しない** |
| 公開設定 | **公開する** |
| タイムラインに投稿 | **する** |

**クーポンの説明**に貼り付け：

```
焼き芋 1本 50円引き

出店のお会計のときに、この画面を見せてください。
おひとり様1回かぎりです。
```

> **50円引きは仮の金額です。** 変えるときは、`line/design/pop-a5-friend.html` の同じ数字も直して
> `npm run line:build` を実行してください（POPの表示も揃います）。

### ② 雨の日ありがとうクーポン（あとでもOK）

| 項目 | 入れるもの |
|---|---|
| クーポン名 | `雨の日ありがとうクーポン` |
| 利用可能回数 | 1回のみ |
| 抽選 | 使用しない |
| 公開設定 | **公開する** |

```
2本以上お買い上げで、焼き芋をもう1本サービスします。

足元の悪いなか来てくださって、ありがとうございます。
本日の出店かぎり有効です。
```

**このクーポンは配信しません。** 雨の日に現場で口頭で伝えて、プロフィールから取ってもらいます。→ **0通で配れます。**

## STEP 5｜ショップカードを作る（10分）

★ これも**あいさつメッセージより先**です。

**ホーム → ショップカード → 作成**

| 項目 | 設定 |
|---|---|
| デザイン | 好きなものを選んでOK（茶色・オレンジ系がとろりに合います） |
| ゴールまでのポイント数 | **5** |
| 有効期限 | **最後の取得から180日** |
| カード取得ポイント | **1ポイント**（＝カードを作った時点で1つ付きます） |
| 有効期限の通知 | **する** |
| ポイント付与制限 | **1日1回** |
| 利用ガイド | 下の文面を貼り付け |

**特典チケット（ゴール時）**

| 項目 | 設定 |
|---|---|
| 特典チケット名 | `焼き芋 1本プレゼント` |
| 有効期限 | **発行から30日** |
| 利用可能回数 | 1回のみ |

**利用ガイド**に貼り付け：

```
お会計1回につき、1ポイントたまります。
5ポイントで、焼き芋を1本プレゼントします。

・お会計のとき、レジ横のQRコードを読み取ってください
・ポイントは1日に1回までです
・最後にポイントを取得してから180日で、カードの有効期限が切れます
```

**作ったら必ず**：右上のメニューから **ポイント付与用QRコードをダウンロード** して、
パソコンの `line/assets/qr-point.png` として保存してください（STEP 9で使います）。

> **1会計1ポイントにしているのは、行列を止めないためです。**
> 金額に応じてポイントを変えると、レジで計算が発生して現場が詰まります。

## STEP 6｜あいさつメッセージを入れる（10分）

**ホーム → あいさつメッセージ**

**5つの吹き出し**に分けて登録します。「＋追加」で吹き出しを増やせます。

### 1通目（テキスト）

`{ユーザーの表示名}` は、**入力欄の上にある「ユーザーの表示名」ボタンを押して挿入**してください。手で打つと動きません。

```
{ユーザーの表示名}さん、友だち追加ありがとうございます。
お芋やとろりです🍠
```

### 2通目（テキスト）

```
とろりの焼き芋は、低温でじっくり時間をかけて焼いています。
甘くするために何かを足すことはしていません。時間だけがつくる甘さです。

割ったときに、スプーンですくえるくらいの蜜が出てきます。
```

### 3通目（テキスト）

```
このLINEでは、次の3つをお届けします。

📅 次にどこへ出店するか
🍠 いちばんおいしい食べ方・保存のしかた
🛒 おうちで食べたいときのお取り寄せ

下のメニューから、いつでも見られます。
```

### 4通目（クーポン。貼り付ける文章はありません）

「＋追加」→ **クーポン** を選び、STEP 4で作った **友だち追加ありがとうクーポン** を指定します。

### 5通目（テキスト）

```
上のクーポンは、次の出店でそのまま使えます。

それから、ポイントカードもあります。
お会計のときにレジ横のQRコードを読み取ると1ポイント。
5ポイントで焼き芋を1本プレゼントします。

お会いできるのを楽しみにしています。
```

> 吹き出しは**最大5つ**です。上でちょうど5つ使い切っています。
> 何か足したいときは、2通目と3通目をつなげて1つにすると枠が空きます。
> **何人に届いても0通**なので、内容を削るよりつなげるほうが得です。

保存したら、右上の **変更を保存** を押します。

## STEP 8｜リッチメニューを作る（15分）

**トークルーム管理 → リッチメニュー → 作成**

### 基本設定

| 項目 | 入れるもの |
|---|---|
| タイトル | `とろり メインメニュー（冬）` |
| 表示期間 | 開始日＝今日／終了日＝空欄 |
| メニューバーのテキスト | `メニュー` |
| メニューのデフォルト表示 | **表示する** |

### コンテンツ設定

1. **テンプレートを選択** → 「大」の中から **3列×2行（6分割）** を選ぶ
2. **背景画像をアップロード** → `line/out/richmenu-winter.png`
3. 6つのマスに、それぞれアクションを設定します

| マス | 画像の見た目 | タイプ | 入れるもの | リンクの表示名 |
|---|---|---|---|---|
| 左上 | 次の出店 | リンク | `https://サイトのURL#schedule` | `次の出店` |
| 中上 | おうちに届ける | リンク | `https://SquareストアのURL` | `ネット販売` |
| 右上 | ショップカード | リンク | ショップカードのURL（下記） | `ショップカード` |
| 左下 | おいしい食べ方 | リンク | `https://サイトのURL#howto` | `食べ方` |
| 中下 | とろりのこと | リンク | `https://サイトのURL#about` | `とろりについて` |
| 右下 | きいてみる | **テキスト** | `質問` | — |

**ショップカードのURL**は、**ホーム → ショップカード → 作成済みのカードを開く → カードのURL** からコピーできます。

**リンクの表示名は必ず入れてください。** あとで「どのボタンが押されているか」が分析画面で見られるようになり、
配信内容を決めるときの材料になります。

4. **保存** → 一覧で **表示** に切り替える

> **⚠ URLがまだ決まっていない場合**
> リンク先が決まっていないマスは、タイプを **テキスト** にして、次のように入れておきます。
> - 左上「次の出店」→ テキスト `出店`（STEP 7の①が自動で返ります）
> - 中上「おうちに届ける」→ テキスト `通販`（②が返ります）
> - 左下「おいしい食べ方」→ テキスト `食べ方`（③が返ります）
>
> **これで、サイトがなくてもメニューは全部ちゃんと動きます。**
> サイトを公開したら、リンクに差し替えてください。

### 夏版（4〜9月）に切り替えるとき

同じ手順で `line/out/richmenu-summer.png` を使って**もう1つ**作り、表示を切り替えます。
アクションは、中上を「冷凍焼き芋・干し芋」、左下を「凍らせて食べる」に読み替えるだけで、リンク先は同じです。

**ホーム → プロフィール → プラグインを追加**

上から順に3つ足します。

## STEP 10｜QRコードを取り込んで、POPを印刷する（15分）

### QRコードを2つ集める

| 何のQR | どこから | 保存先のファイル名 |
|---|---|---|
| 友だち追加用 | **ホーム → 友だち追加ガイド → QRコード → 作成／ダウンロード** | `line/assets/qr-friend.png` |
| ポイント付与用 | **ホーム → ショップカード → カードを開く → ポイント付与用QRコード** | `line/assets/qr-point.png` |

> **この2つは別物です。** 取り違えると、ポイントを付けたいのに友だち追加の画面が出てしまいます。
> 保存するときは、上の表のファイル名をそのまま使ってください（名前が違うと入りません）。

### 印刷用のPDFを作る

パソコンのターミナルで、このリポジトリのフォルダに移動して実行します。

```bash
npm run line:build
```

`line/out/` に4つのPDFができます。

### 印刷する

| ファイル | 用紙 | 置く場所 |
|---|---|---|
| `pop-a5-friend.pdf` | A5・普通紙 | レジのすぐ横 |
| `pop-a6-shopcard.pdf` | A6・普通紙 | レジのすぐ横（もう1枚） |
| `pop-a4-schedule.pdf` | A4・普通紙 | テントの支柱・のぼりの脇 |
| `card-a4-10up.pdf` | A4・厚めのマット紙 | 切って、商品の袋に1枚ずつ |

★ **印刷設定で「実際のサイズ」「拡大縮小なし（100%）」を選んでください。**
「用紙に合わせる」にするとQRが縮んで、読み取りにくくなります。

POPはクリアファイルに入れると、風で飛ばず雨にも強くなります。

## STEP 11｜認証済みアカウントを申請する（10分・無料）

**設定 → アカウント設定 → アカウント認証** から申請します。

審査に通ると：
- **LINEアプリ内の検索に出るようになります**（＝知らない人に見つけてもらえる）
- バッジが灰色から**青**になり、信用されやすくなります
- 公式のポスターなどの販促物が使えるようになります

**無料です。** 審査に1〜10営業日かかるので、早めに出しておいてください。

申請には次が必要です。揃っていないものは、揃ってから出しても構いません。

- 事業者名（屋号または個人名）
- 業種
- 所在地・電話番号
- 事業内容が分かる情報（公式サイトのURL、または営業許可証）

> **認証済みになると、アカウント名は変更できなくなります。** `お芋やとろり` で確定してから申請してください。

## STEP 12｜通しで確認する（10分）★これが一番大事
