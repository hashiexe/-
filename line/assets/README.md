# assets — QRコードの置き場所

このフォルダに、**決まった名前で**画像を置くだけで、POPやカードに自動で入ります。
（サイト側の `site/assets/` と同じ考え方です。コードは触りません）

| ファイル名 | 何のQRか | どこで手に入るか |
|---|---|---|
| `qr-friend.png` | **友だち追加用** | LINE公式アカウントマネージャー → ホーム → 友だち追加ガイド → QRコード → ダウンロード |
| `qr-point.png` | **ショップカードのポイント付与用** | LINE公式アカウントマネージャー → ショップカード → ポイント付与用QRコード → ダウンロード |

> この2つは**別のQRコードです**。取り違えると、ポイントを付けたいのに友だち追加の画面が出てしまいます。

置いたあと、印刷用のPDFを作り直します。

```bash
npm run line:build
```

まだ置いていないときは、QRの場所に「ここにQRコードが入ります」という案内枠が出ます。
レイアウトの確認だけなら、QRがなくても先に進められます。

画像は正方形（600×600px 以上）で、余白の白は残したまま保存してください。
QRのまわりの白い余白は読み取りに必要なので、切り詰めないでください。
