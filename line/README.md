# お芋やとろり LINE公式アカウント

対面で会えたお客さまと、**次にまた会うため**のアカウントです。
新しいお客さまを集める場所ではなく、一度買ってくれた人を逃さないための場所として設計しています。

運用コストは **0円**（無料のコミュニケーションプランのみ）。
ふだんの運用で開くのは LINE公式アカウントマネージャーだけで、コードは触りません。

---

## とろりロードのどこに効くか

このアカウントは、ロードマップ（`src/data/seed.ts`）の1ステージではなく、ワールド3〜4をまたいで効きます。

| ステージ | LINEが担うこと |
|---|---|
| `s3-4` SNSを開設する | このアカウントの開設そのもの |
| `s3-5` リピーターに再会する | **ショップカード**。「前も買ったよ」を数字で見えるようにする |
| `s3-6` 月4回の定期出店 | 月初の出店カレンダー配信＋リッチメニューの常設案内 |
| `s3-1` いものすけを看板にする | リッチメニュー・カバー・POPでいものすけを統一 |
| `s3-2` マリアージュセット | ショップカード2周目の特典をコーヒーにして客単価を上げる |
| `s2-3`〜`s2-10` 1出店で◯本／利益◯円 | 友だち追加特典クーポンで再来店を作り、1回の出店の本数を積む |
| `s4-2` ECサイト公開 / `s4-5` リピート通販 | リッチメニューから Square ストアへ常時導線 |
| `s1-6` 冷凍ストック / `s-dev2` 犬用おやつ | 焼き芋が売れない4〜9月の主力としてLINEで訴求 |

## 設計のいちばん大事な考え方

**「押す」（配信）は月2回まで。それ以外の情報は全部「置いて待つ」。**

無料プランで送れるのは **月200通** です。1通は「1人に届いたら1通」なので、
友だちが増えるほど、送れる回数は減ります。

| 友だちの数 | 無料で送れる一斉配信 |
|---|---|
| 〜50人 | 月4回 |
| 〜66人 | 月3回 |
| 〜100人 | **月2回** |
| 〜200人 | 月1回 |
| 200人超 | ほぼ送れない → 有料プランを検討する目安 |

一方で、**何回使っても1通も減らない機能**があります。ここに情報を全部寄せます。

- あいさつメッセージ（友だち追加したときに自動で届く。最大5通）
- 応答メッセージ（キーワードへの自動返信。何回でも無料）
- 1:1トークでの手動の返信
- リッチメニュー（トーク画面の下に出る6分割のメニュー）
- プロフィールページ
- ショップカード／クーポン（**配信せずリンクを置くだけなら0通で配れます**）
- LINE VOOM への投稿

> **出店のたびに前日リマインドを配信すると、通数がすぐ尽きます。**
> 前日の告知は LINE VOOM と、リッチメニューの「次の出店」ボタン（→ 公式サイトの出店スケジュール）に逃がします。
> サイトのスケジュールは Google スプレッドシート連動なので、**シートに1行足すだけでLINE側も最新になります。LINEでの更新作業はゼロです。**

くわしくは [配信設計.md](./配信設計.md) を見てください。

## このフォルダの中身

```
line/
├─ README.md          ← いまここ。全体の設計と開設手順
├─ 設定シート.md        管理画面にコピペする文言ぜんぶ
├─ 配信設計.md          月200通の使い方・年間の配信計画・文面テンプレ
├─ 現場ツール.md         POPの使い方・声かけのしかた・印刷手順
├─ 入力項目リスト.md      まだ決まっていないことのリスト（★先にここを埋めます）
├─ build.mjs           デザインからPNG/PDFを書き出すスクリプト
├─ design/            デザインのもと（HTML）。色や文言はここを直します
├─ assets/            QRコードを置く場所（→ assets/README.md）
└─ out/               書き出し済みのPNG / PDF。★LINEに上げるのはここのファイル
```

`out/` のファイルはリポジトリに入っているので、**ふだんは build を実行する必要はありません**。
デザインや文言を変えたときだけ、次を実行します。

```bash
npm run line:build
```

追加のインストールは要りません（パソコンの Chrome をそのまま使います）。

## 開設の手順

### 1. アカウントを作る

1. [LINE for Business](https://www.linebiz.com/jp/) から LINE公式アカウントを作成
2. アカウント名は **`お芋やとろり`**（検索で見つけてもらうため、屋号そのまま）
3. ベーシックID（`@` から始まるID）は無料で自動発行されます。好きな文字列にする「プレミアムID」は有料なので取りません
4. 料金プランは **コミュニケーションプラン（無料）** を選びます

### 2. 認証済みアカウントを申請する（無料・おすすめ）

審査に通ると、LINEアプリ内の検索結果に出るようになり、バッジも青（認証済み）になります。**無料です。**
申請には屋号・業種・所在地などが必要なので、[入力項目リスト.md](./入力項目リスト.md) の内容が揃ってから申請してください。

### 3. プロフィールを整える

- **カバー画像**：`out/cover.png`（1080×878）をアップロード
- **プロフィール画像**：いものすけの画像を使います
- ボタン・追加情報・プラグインの設定は [設定シート.md](./設定シート.md) の「4. プロフィール」を見てください

### 4. あいさつメッセージ・応答メッセージを入れる

[設定シート.md](./設定シート.md) の文面をそのままコピペします。
どちらも**何通送っても無料**なので、ここを充実させるほど得です。

### 5. リッチメニューを設定する

1. LINE公式アカウントマネージャー → **トークルーム管理 → リッチメニュー → 作成**
2. テンプレートは **「大」の6分割**（3列×2行）を選ぶ
3. 背景画像に `out/richmenu-winter.png`（10〜3月）をアップロード
4. 各マスのアクションを設定（リンク先は [設定シート.md](./設定シート.md) の「1. リッチメニュー」を参照）
5. 表示期間を設定して保存 → **表示する** に切り替え

4〜9月は `out/richmenu-summer.png` に差し替えます。

### 6. ショップカードとクーポンを作る

[設定シート.md](./設定シート.md) の「5. ショップカード」「6. クーポン」のとおりに設定します。
作ったあと、**ポイント付与用のQRコードをダウンロードして `assets/qr-point.png` に置いてください。**

### 7. QRコードを取り込んで、現場のPOPを印刷する

1. 友だち追加用のQRを `assets/qr-friend.png` に置く
2. ポイント付与用のQRを `assets/qr-point.png` に置く
3. `npm run line:build` を実行
4. `out/` のPDFを印刷（→ [現場ツール.md](./現場ツール.md)）

### 8. 公式サイトとつなぐ

公式サイト（`site/`）は別のブランチにあります。統合したあとで次を行います。

- `site/content.js` の `links.line` に、友だち追加URL（`https://lin.ee/xxxxxxx`）を入れる
- リッチメニューのリンク先を、公開したサイトのURL＋アンカー（`#schedule` / `#howto` / `#about`）に置き換える
- サイトの `SPREADSHEET_SETUP.md` で設定したスプレッドシートが、そのままLINEの出店情報源になります

## 有料プランに移るタイミング

次のどちらかを **2ヶ月続けて**満たしたら、ライトプラン（5,000円/月・5,000通）を検討します。

- 友だちが **200人を超えた**（無料では月1回しか送れなくなる）
- **配信1回あたりの売上が5,000円を超えている**（＝送るほど儲かる状態になっている）

逆に言えば、それまでは無料で十分です。焦って有料にしないでください。
