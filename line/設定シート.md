# 設定シート — 管理画面にコピペするもの全部

LINE公式アカウントマネージャーに入力する文言を、ここにまとめています。
**この中の `{ }` で囲まれた部分だけ、実際のURLや金額に置き換えてから**コピペしてください。

| 差し込み | 入れるもの | 例 |
|---|---|---|
| `{サイト}` | 公式サイトのURL | `https://oimoyatorori.vercel.app` |
| `{ショップ}` | Squareオンラインストアの URL | `https://oimoyatorori.square.site` |
| `{ショップカード}` | ショップカードのURL（作成後に発行されます） | |
| `{クーポン}` | 友だち追加特典クーポンのURL（作成後に発行されます） | |

未確定のものは [入力項目リスト.md](./入力項目リスト.md) にまとめています。

## 1. リッチメニュー

**設定場所**：トークルーム管理 → リッチメニュー → 作成
**テンプレート**：「大」の6分割（3列×2行）
**画像**：`out/richmenu-winter.png`（10〜3月） / `out/richmenu-summer.png`（4〜9月）
**メニューのタイトル**（お客さまには見えません）：`とろり メインメニュー（冬）` / `（夏）`
**メニューバーのテキスト**：`メニュー`
**メニューのデフォルト表示**：表示する

### 冬版（10〜3月）のアクション設定

| 位置 | 見た目 | アクション | 設定する内容 |
|---|---|---|---|
| 左上 | 次の出店 | リンク | `{サイト}#schedule` |
| 中央上 | おうちに届ける | リンク | `{ショップ}` |
| 右上 | ショップカード | リンク | `{ショップカード}` |
| 左下 | おいしい食べ方 | リンク | `{サイト}#howto` |
| 中央下 | とろりのこと | リンク | `{サイト}#about` |
| 右下 | きいてみる | テキスト | `質問` |

### 夏版（4〜9月）のアクション設定

冬版から変えるのは3か所だけです。

| 位置 | 見た目 | アクション | 設定する内容 |
|---|---|---|---|
| 中央上 | 冷凍焼き芋・干し芋 | リンク | `{ショップ}` |
| 左下 | 凍らせて食べる | リンク | `{サイト}#howto` |
| 中央下 | とろりのこと | リンク | `{サイト}#about` |

> 「犬用お菓子の開発（`s-dev2`）」がクリアになったら、中央下を「わんちゃんおやつ」に差し替えます。
> 画像側の差し替え方は `design/richmenu-summer.html` のコメントに書いてあります。

**リンクの表示名**（分析画面に出る名前。お客さまには見えません）：
`次の出店` / `ネット販売` / `ショップカード` / `食べ方` / `とろりについて` / `質問`
→ どのボタンが押されているかは、あとで配信内容を決めるときの材料になります。必ず入れてください。

## 2. あいさつメッセージ（友だち追加されたとき）

**設定場所**：ホーム → あいさつメッセージ
**通数**：何人に届いても **0通**（無料メッセージを消費しません）

以下を **5つの吹き出し**に分けて登録します。
`{ユーザーの表示名}` は管理画面の「ユーザーの表示名」ボタンから挿入してください（手打ちでは動きません）。

**1通目**
```
{ユーザーの表示名}さん、友だち追加ありがとうございます。
お芋やとろりです🍠
```

**2通目**
```
とろりの焼き芋は、低温でじっくり時間をかけて焼いています。
甘くするために何かを足すことはしていません。時間だけがつくる甘さです。

割ったときに、スプーンですくえるくらいの蜜が出てきます。
```

**3通目**
```
このLINEでは、次の3つをお届けします。

📅 次にどこへ出店するか
🍠 いちばんおいしい食べ方・保存のしかた
🛒 おうちで食べたいときのお取り寄せ

下のメニューから、いつでも見られます。
```

**4通目**（テキストではなくクーポンの吹き出し）
→ 管理画面で「＋追加 → クーポン」を選び、**6. クーポン**で作った「友だち追加ありがとうクーポン」を指定します。文章は入れません。

**5通目**
```
上のクーポンは、次の出店でそのまま使えます。

それから、ポイントカードもあります。
お会計のときにレジ横のQRコードを読み取ると1ポイント。
5ポイントで焼き芋を1本プレゼントします。

お会いできるのを楽しみにしています。
```

> 吹き出しは**最大5つ**です。上でちょうど使い切っています。

## 3. 応答メッセージ（キーワードの自動返信）

**設定場所**：自動応答メッセージ → 応答メッセージ
**通数**：何回返しても **0通**
**一致条件**：すべて「部分一致」

> ここが充実しているほど、一斉配信を使わずに済みます。**この表が、無料運用のいちばんの武器です。**

### ① 出店予定

キーワード：`出店` `どこ` `予定` `スケジュール` `今度` `いつ` `次`
```
次の出店予定は、こちらでいつでも見られます。

📅 {サイト}#schedule

天候などで変更になることがあるので、出発前にもう一度ご確認ください。
（このページは、予定が決まりしだいすぐ更新しています）
```

### ② ネット販売

キーワード：`通販` `ネット` `買いたい` `送って` `発送` `お取り寄せ` `注文`
```
冷凍焼き芋・干し芋は、こちらからご注文いただけます。

🛒 {ショップ}

クール便でお届けします。
送料や発送までの日数も、上のページに書いています。
```

### ③ 食べ方・保存

キーワード：`保存` `冷凍` `温め` `あたため` `食べ方` `解凍` `レンジ` `トースター` `賞味`
```
いちばんおいしい食べ方と、保存のしかたをまとめています。

🍠 {サイト}#howto

冷たいままでも、温め直しても、凍らせてもおいしいです。
季節によっておすすめが変わるので、ときどきのぞいてみてください。
```

### ④ 原材料・アレルギー

キーワード：`アレルギー` `原材料` `成分` `添加物`
```
原材料と保存方法は、こちらにまとめています。

❓ {サイト}#faq

ご心配なことがあれば、このトークにそのまま書いてください。
できるだけ早くお返事します。
```

### ⑤ 取り置き・予約

キーワード：`予約` `取り置き` `とりおき` `確保`
```
出店日の取り置きは、このトークで承っています。

・ご希望の本数
・受け取りに来られるおおよその時間

この2つを送ってください。折り返しお返事します。
（数に限りがあるため、ご希望に添えないこともあります）
```

### ⑥ わんちゃん向け

キーワード：`犬` `わんちゃん` `ペット` `愛犬`
```
わんちゃん用の焼き芋おやつを準備中です🐕

出来上がったら、いちばんにこのLINEでお知らせします。
（さつまいもだけで作る、味つけなしのおやつです）
```
> 商品化（`s-dev2`）が済んだら、この文面を実際の商品案内に差し替えてください。

### ⑦ ポイント・クーポン

キーワード：`ポイント` `カード` `クーポン` `スタンプ`
```
ポイントカードは、下のメニューの「ショップカード」から見られます。

・お会計1回につき 1ポイント
・5ポイントで焼き芋1本プレゼント

お会計のとき、レジ横のQRコードを読み取ってください。
```

### ⑧ どれにも当てはまらないとき

**設定場所**：自動応答メッセージ →「キーワードが一致しなかった場合」
```
メッセージありがとうございます。
出店の合間に、夫婦2人でお返事しています。
少しお時間をいただくことがありますが、必ずお返事します🍠

お急ぎでなければ、下のメニューからもだいたいのことが分かります。
```

## 4. プロフィール

**設定場所**：ホーム → プロフィール

| 項目 | 設定する内容 |
|---|---|
| カバー画像 | `out/cover.png`（1080×878） |
| プロフィール画像 | いものすけ（`design/imonosuke.svg` を正方形の画像に書き出したもの） |
| ステータスメッセージ | `低温でじっくり。時間だけがつくる甘さの焼き芋です。` |
| ボタン | 「トーク」「位置情報」を表示 |

**追加情報**

| 項目 | 内容 |
|---|---|
| 業種 | 食料品・スイーツ |
| 営業時間 | 出店日のみ（→ [入力項目リスト.md](./入力項目リスト.md)） |
| ウェブサイト | `{サイト}` |
| Instagram | （取得したら） |

**プラグイン**（プロフィール画面に置ける小さなパーツ。無料です）

1. **ショップカード** — ポイントの残り数がひと目で分かります
2. **クーポン** — 配信しなくても、ここから取ってもらえます
3. **お知らせ** — リンク先を `{サイト}#schedule` にします

> カバー画像の**左下**には、プロフィール写真の丸とアカウント名が重なります。
> `design/cover.html` はそこを空けて作ってあるので、写真に差し替えるときも同じルールを守ってください。

## 5. ショップカード

**設定場所**：ショップカード → 作成
**通数**：0通（何人が使っても無料）

現場でレジが止まらないことを最優先にした設計です。**金額に応じてポイントを変えると、行列が止まります。**

| 項目 | 設定 | なぜそうするか |
|---|---|---|
| ゴールまでのポイント数 | **5** | 4〜5回で1周が、いちばん続きます |
| 特典（ゴール時） | **焼き芋 1本プレゼント** | 原価が読めて、次の来店理由にもなります |
| 有効期限 | **最後にポイントを取得してから180日** | 焼き芋は季節商材なので、シーズンをまたげる長さにします |
| 特典チケットの有効期限 | **30日** | もらったまま忘れられないように |
| カード有効期限が切れる前の通知 | **する** | 0通で送れる貴重なリマインドです |
| ポイント付与の方法 | **1回のお会計につき 1ポイント** | 計算がいらないので、混んでいても一瞬で終わります |
| 友だち追加時のボーナス | **1ポイント** | 最初の1歩を軽くして、カードを始めてもらいます |

**2周目以降の特典**（`s3-2` マリアージュセット、`s3-coffee` の達成後に変更する）

ゴール特典を **「焼き芋＋コーヒーのマリアージュセット」** に切り替えます。
同じ「1本プレゼント」を繰り返すより、客単価が上がり、セットの存在も知ってもらえます。

**設定が終わったら**：ポイント付与用のQRコードをダウンロードして、`assets/qr-point.png` に置いてください。
レジ横に立てるPOP（`out/pop-a6-shopcard.pdf`）に自動で入ります。

## 6. クーポン

**設定場所**：クーポン → 作成

### ① 友だち追加特典（いちばん大事）

| 項目 | 設定 |
|---|---|
| クーポン名 | `友だち追加ありがとうクーポン` |
| 特典 | **焼き芋 1本 50円引き** |
| 有効期限 | 発行日から **30日** |
| 使用可能回数 | **1回のみ** |
| 抽選 | **なし**（全員当たり） |
| 表示設定 | タイムラインに投稿する：**する** |

あいさつメッセージの4通目に紐づけます。
**現場で「いま追加してくれたらこの場で50円引きです」と言えることが、友だちが増える最大の理由になります。**

### ② 雨の日クーポン（配信しないで使う）

| 項目 | 設定 |
|---|---|
| クーポン名 | `雨の日ありがとうクーポン` |
| 特典 | **焼き芋 1本サービス**（2本以上お買い上げの方） |
| 有効期限 | その出店日のみ |
| 使用可能回数 | 1回のみ |

**配信しません。** 悪天候の出店日に、その場でお客さまへ口頭で伝え、
プロフィールのクーポンプラグインから取ってもらいます。→ **0通で配れます。**

### ③ シーズン開幕クーポン（年1回だけ配信に載せる）

| 項目 | 設定 |
|---|---|
| クーポン名 | `シーズン開幕クーポン` |
| 特典 | **2本以上で 100円引き** |
| 有効期限 | 10月中 |
| 抽選 | **あり／当選確率 50%** |

10月の1回目の配信に同梱します。抽選にすると開封率が上がり、1通の価値が上がります。
→ 文面は [配信設計.md](./配信設計.md) を見てください。
