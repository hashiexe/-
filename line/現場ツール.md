# 現場ツール — 出店テントで友だちを増やす

友だちは、**出店の現場でしか増えません。** ここが増えないと、LINEはただの空箱になります。
このページの4つを印刷して持っていくだけで、追加率がはっきり変わります。

---

## 準備（最初の1回だけ）

1. LINE公式アカウントマネージャーから **友だち追加用QRコード**をダウンロード → `assets/qr-friend.png` に置く
2. ショップカードの管理画面から **ポイント付与用QRコード**をダウンロード → `assets/qr-point.png` に置く
3. 金額や特典が仮のままなら、`design/` の該当ファイルを直す（→ [入力項目リスト.md](./入力項目リスト.md)）
4. 書き出す

```bash
npm run line:build
```

`out/` に印刷用のPDFができます。

---

## 4つの道具

| 印刷するもの | サイズ | 置く場所 | ねらい |
|---|---|---|---|
| `out/pop-a5-friend.pdf` | A5 | **レジのすぐ横** | その場で追加してもらう |
| `out/pop-a6-shopcard.pdf` | A6 | **レジのすぐ横（もう1枚）** | ポイントを付ける |
| `out/pop-a4-schedule.pdf` | A4 | テントの支柱・のぼりの脇 | 通りすがりの人に知ってもらう |
| `out/card-a4-10up.pdf` | A4に10枚 | **商品の袋に1枚入れる** | 家に帰ってから追加してもらう |

### 印刷のしかた

- **A5・A6・A4のPOP**：普通紙でOK。100円ショップのクリアファイルやカードスタンドに入れると、風で飛ばず雨にも強くなります
- **名刺サイズのカード**：厚めのマット紙（0.2mm前後）に印刷して、うすいグレーの線で切ります。1枚のA4から10枚とれます
- プリンタの設定で **「実際のサイズ」「拡大縮小なし（100%）」** を選んでください。「用紙に合わせる」にすると、QRが小さくなって読み取りにくくなります

## 声かけのしかた

**いちばん大事なのは、その場で得することを先に言うことです。**
「LINEやってます」だけでは、ほとんど追加してもらえません。

### お会計のときに（これが基本）

> 「ありがとうございます。
> 次いつどこに出るか、LINEでお知らせしてるんです。
> **いま追加してもらえたら、そのお芋が50円引きになります。**」

- 「次いつ出るか分からない」という、お客さまが実際に困っていることから入ります
- 特典を**後払い（次回）ではなく、その場**にするのが肝心です。「次回使えます」は追加率が大きく落ちます
- QRを指さして「これです」と示すところまでやります

### すでに友だちの方には

> 「ありがとうございます。ポイント、こちらのQRで付けられます。
> **5回で1本プレゼントです。**」

レジ横のA6のPOPを指さすだけで通じます。

### 買わずに見ているだけの方には

> 「今日のは◯◯（品種）で、◯日寝かせたやつです。
> よかったら次の出店だけでも、こちらから見られます」

売り込まずに、A4の掲示を示すだけにします。**買わない人を友だちにできると、次につながります。**

### お渡しのときに

商品の袋に、名刺サイズのカードを1枚入れます。何も言わなくて構いません。
**家で食べたあと「もう一回食べたい」と思った瞬間に、手元にQRがある**のが大事です。

## 現場でのよくある詰まり

| 起きること | 対処 |
|---|---|
| QRが読み取れない | 印刷が小さすぎるか、拡大縮小されています。100%で刷り直してください |
| 「あとで追加します」と言われる | 追いかけません。カードを袋に入れて渡すだけにします |
| ポイント用と友だち追加用のQRを取り違える | POPの見出しで見分けます（「LINEでお知らせします」＝追加用／「ポイントカード」＝ポイント用） |
| 混雑してポイントを付けられない | 無理に付けません。次回に回します。**行列を止めるくらいなら、ポイント1つは捨てます** |

## 出店ごとに見ておく数字

出店から帰ったら、LINE公式アカウントマネージャーの **分析 → 友だち** を見ます。

- **その日に何人増えたか**
- **その日の販売本数のうち、何割が追加してくれたか**

「50本売れて5人追加」なら10%。ここを **20%** に上げることを当面の目標にします。
声かけの言い方を変えると、この数字はすぐ動きます。**言い方を変えた日は、メモしておいてください。**

この数字は、ロードマップの `s3-5 リピーターに再会する` に直接つながります。
