# 配信設計 — 月200通をどう使うか

無料プランで送れるのは **月200通**です。ここでは「いつ・何を送るか」と、そのまま使える文面をまとめています。

---

## 1. まず、送らずに済ませる

配信を考える前に、**送らなくても届く方法**を先に使い切ります。

| 伝えたいこと | 配信せずに済ませる方法 | 消費する通数 |
|---|---|---|
| 次の出店はいつ・どこ | リッチメニュー「次の出店」→ サイトの出店スケジュール | **0通** |
| 明日出ます | LINE VOOM に投稿 | **0通** |
| 商品・価格・売り切れ | リッチメニュー → Squareストア | **0通** |
| 食べ方・保存方法 | 応答メッセージ（キーワード自動返信） | **0通** |
| クーポンを配りたい | プロフィールのクーポンプラグインから取ってもらう | **0通** |
| ポイントの残り | ショップカード（期限前の通知も0通） | **0通** |

**出店スケジュールは、Googleスプレッドシートに1行足すだけでサイトに反映されます。**
LINE側では何もしません。これが、月4回出店しても通数が減らない理由です。

---

## 2. それでも配信する2回

「置いて待つ」では届かないことだけを配信します。**月2回**が基本です。

### 配信① 月初：今月の出店カレンダー（毎月1日〜3日）

その月にどこへ出るかを、1通にまとめます。**この1通が、月でいちばん売上に効きます。**

### 配信② 月内のどこか1回：季節・新商品・お知らせ

新しい商品ができたとき、シーズンが変わるとき、年末年始など。
特に用がない月は、**送らないのが正解です。** 無理に送るとブロックされます。

### 送る時間

**金曜か土曜の 18:00〜20:00。** 週末の出店の直前に、家でスマホを見ている時間帯です。
深夜（22時以降）と早朝（8時前）には絶対に送らないでください。ブロックの一番の原因になります。

---

## 3. 1年の流れ

焼き芋は、売れる時期と売れない時期がはっきり分かれます。それに合わせて、伝えることを変えます。

| 時期 | 状況 | ①月初カレンダー | ②もう1通 |
|---|---|---|---|
| **10月** | シーズン開幕 | 今月の出店 | **開幕のお知らせ＋抽選クーポン** |
| **11月** | 立ち上がり | 今月の出店 | （送らない） |
| **12月** | 最需要期・ギフト | 今月の出店 | **年末年始の出店予定・冷凍のギフト** |
| **1月** | 寒さで好調 | 今月の出店 | （送らない） |
| **2月** | 最盛期 | 今月の出店 | **いちばん甘い時期のお知らせ** |
| **3月** | 終わりが近い | 今月の出店 | **今シーズンの生の焼き芋はここまで** |
| **4月** | 端境期 | 今月の出店 | **冷凍・干し芋に切り替わる案内** |
| **5〜7月** | 閑散期 | 今月の出店 | （送らない） |
| **8月** | 夏の商材 | 今月の出店 | **凍らせて食べる・わんちゃんおやつ** |
| **9月** | 開幕直前 | 今月の出店 | **来月からシーズンです、の予告** |

年間で **18〜20通ぶんの配信回数**です。友だちが100人でも、余裕をもって無料枠に収まります。

## 4. 文面テンプレート

そのままコピーして、日付と場所だけ差し替えてください。
**絵文字は1通に3〜4個まで。** 多いと広告に見えて、ブロックされやすくなります。

### ① 月初：今月の出店カレンダー

```
こんばんは、お芋やとろりです🍠

◯月の出店予定が決まりました。

📅 ◯月◯日（土）イケ・サンパーク 10:00-16:00
📅 ◯月◯日（土）◯◯◯◯ 10:00-16:00
📅 ◯月◯日（土）イケ・サンパーク 10:00-16:00

今月は紅はるかが◯◯で、いつもより蜜が多く出ています。
売り切れることがあるので、確実な方はお昼までにお越しください。

最新の予定はこちら
{サイト}#schedule
```

### ② 10月：シーズン開幕＋抽選クーポン

```
お待たせしました。今シーズンの焼き芋が始まります🍠

夏のあいだ寝かせておいたさつまいもが、いちばん甘くなる季節です。
◯月◯日から、イケ・サンパークに戻ります。

開幕のごあいさつに、クーポンを1枚。
（抽選です。ハズレても、また来月お配りします）

📅 ◯月◯日（土）10:00-16:00
```
→ 抽選クーポン「シーズン開幕クーポン」を添付します（→ [設定シート.md](./設定シート.md)）

### ③ 12月：年末年始のご案内

```
今年もありがとうございました🍠

年末年始の出店予定です。

📅 12月◯日（土）イケ・サンパーク 10:00-16:00 ← 年内最後
📅 1月◯日（土）イケ・サンパーク 10:00-16:00 ← 初出店

冷凍焼き芋は、帰省のおみやげにも使っていただけます。
クール便でお送りできるので、実家に直送もできます。

🛒 {ショップ}
```

### ④ 4月：冷凍・干し芋への切り替え

```
今シーズンの焼きたての販売は、先月でひと区切りとなりました🍠

ここからの季節は、冷凍焼き芋と干し芋でお届けします。

{サイト}#howto
```

### ⑤ 悪天候で中止するとき（例外的にその場で送ってよい配信）

```
【本日の出店は中止します】

雨と風が強いため、本日◯月◯日の出店は中止いたします。
楽しみにしてくださっていた方、申し訳ありません。

次回は ◯月◯日（土）に、同じ場所に出ます。
```

> **中止の連絡だけは、通数を気にせず送ってください。**
> 来てくださる方を空振りさせないことが、何より優先です。

## 5. やってはいけないこと

- **月3回を超えて送る** — 通数が尽きるだけでなく、ブロック率がはっきり上がります
- **深夜・早朝に送る** — 通知で起こしてしまいます。ブロックの最大の原因です
- **毎回の出店ごとに前日リマインドを送る** — 4回出店したら4回分×人数で通数が尽きます。VOOMとメニューに逃がしてください
- **絵文字を敷き詰める** — 広告に見えます。1通3〜4個まで
- **中身のない配信をする** — 「今週も頑張ります」だけの配信は、ブロックを増やすだけです。用がない月は送らない

---

## 6. 効果を見るところ

**分析 → メッセージ** で、配信ごとに次の3つを見ます。

| 見るもの | 良い状態 | 悪いときにやること |
|---|---|---|
| **ブロック数** | 配信のたびに増えていない | 増えているなら、回数を減らす／時間帯を見直す |
| **クリック数** | 配信した人の1割以上がリンクを押している | 少ないなら、日付と場所を本文に直接書く |
| **リッチメニューのクリック** | 「次の出店」がいちばん押されている | 別のボタンが多いなら、メニューの並びを変える |

その月の出店の売上と並べて見ると、「配信1回でいくら売れたか」が分かります。
この数字が **5,000円を2ヶ月続けて超えたら**、ライトプラン（5,000円/月）に移る判断ができます。
