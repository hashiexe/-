## クーポン（いまは仮の金額です）

友だち追加特典クーポンの内容。**現場で「いま追加すると得します」と言えることが目的**なので、
金額は小さくても構いません。むしろ「その場で使える」ことのほうが大事です。

- 特典の内容：`焼き芋 1本 50円引き` でよいか　→　**よい／変える（　　　　　　　　）**
- 有効期限：`30日` でよいか　→　**よい／変える（　　　日）**
- 雨の日クーポンの内容：`2本以上で1本サービス` でよいか　→　**よい／変える（　　　　　　　　）**
- シーズン開幕クーポン（10月）：`2本以上で100円引き・当選確率50%` でよいか　→　**よい／変える（　　　　　　　　）**

> 変える場合は、`line/design/pop-a5-friend.html` の文言も直して `npm run line:build` を実行します。

## ショップカード（いまは仮の設定です）

- ゴールまでのポイント数：`5` でよいか　→　**よい／変える（　　　ポイント）**
- ゴールの特典：`焼き芋1本プレゼント` でよいか　→　**よい／変える（　　　　　　　　）**
- ポイントの付け方：`1回のお会計で1ポイント` でよいか　→　**よい／変える（　　　　　　　　）**
- 有効期限：`最後のポイント取得から180日` でよいか　→　**よい／変える（　　　日）**
- 友だち追加時のボーナス：`1ポイント` でよいか　→　**よい／変える（　　　ポイント）**

> 変える場合は、`line/design/pop-a6-shopcard.html` の文言も直して `npm run line:build` を実行します。

- プロフィール画像：いものすけでよいか　→　**よい／写真にする**
