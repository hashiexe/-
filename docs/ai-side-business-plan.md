## 1. 前提条件（ここが全ての制約）

| 項目 | 内容 |
|---|---|
| **目標** | 月3〜5万円の副収入（半年〜9ヶ月以内） |
| **稼働** | 本人 30分/日 ＋ 商談枠 月2〜4回。**平日日中は本業のため不可。平日夜20〜21時 と 土日 が使える** |
| **予算** | 初期＋月額ランニングで 月1〜3万円 |
| **武器** | **エンタープライズIT法人営業5年（ソフトバンク）** ／ 商談・提案力 ／ FP資格 |
| **弱点** | コードが書けない／発信チャネルを持っていない／ツールに詳しくない |
| **禁止事項A** | **IT系の競合になる副業はNG**（勤務先から明示） |
| **禁止事項B** | **オンライン（HP・SNS）での実名・顔出しはNG** |
| **除外** | **FP領域は本人の意欲が続かないため対象外**（第2版で決定） |
| **実行部隊** | Claude（実装・リサーチ・文章・デプロイ・計測・日次レポート） |

### 1.1 「禁止事項B」の正確な意味

本人の意図は**「オンラインに実名を晒したくない」**であり、商談相手・契約書・請求書に実名が出ることは許容。

| 売り方 | 実名のオンライン公開 | 可否 |
|---|---|---|
| スキルマーケット（ココナラ等） | 不要（ニックネーム表示。本人確認は運営に対してのみ） | **○** |
| 1対1の商談 → 業務委託契約 | **不要**（通信販売ではないため特商法の対象外） | **○** |
| アフィリエイト / 広告収益 | 不要（自分が販売者ではないため） | **○** |
| Kindle / note / BOOTH | 不要（ペンネーム可） | **○** |
| 自サイト＋Stripe直販（BtoC通信販売） | 氏名の表示が原則 | **△** |

### 1.2 「禁止事項A」が潰す範囲

勤務先は法人向けにクラウド・SaaS再販・Webソリューション・SIまで手がけるため、
**「ITやWebを法人に売る」領域は広範に競合認定のリスクがある。**

- AI導入支援／業務自動化代行／受託開発／**ホームページ制作** → **リスク大**
- 営業支援・書類作成・コンサルなど**非IT領域のサービス** → **リスク小**
- 個人向け（BtoC）のコンテンツ・ツール → リスク小

月3〜5万円と本業を天秤にかける合理性はない。**グレーゾーンには踏み込まない。**

## 2. 第1版からの方針転換

### 2.1 FP軸を撤回した理由

1. **本人の意欲が続かない。** 飽きたものを半年続ける計画は、計画として成立しない。
2. **SEO上も不利だった。** 金融はGoogleがYMYL（人の財産に関わる領域）として最も厳しく評価する分野で、
   **個人・匿名・実務経験なし**という条件はSEOで最悪の組み合わせ。
   本人が既に `moneybase-fp.com` で集客に失敗しているのは、**能力ではなくジャンル選定の問題**である可能性が高い。
3. 第1版のA案（FPツール×アフィリエイト）は、この壁を「記事ではなくツールを作る」で回避する設計だったが、
   意欲の問題は回避できない。

→ **軸を「FP資格」から「エンタープライズ法人営業5年」に移す。**
   こちらの方が希少性が高く、実務経験があり、市場に明確な困りごとが存在する。

### 2.2 既存サイト `moneybase-fp.com` の扱い

- ドメイン名がFP縛りのため、他ジャンルへの転用は困難。**寝かせる。**
- ただし**「なぜ集客できなかったか」の分析には価値がある**（次に同じ失敗をしないため）。
- 現時点では Claude の実行環境からegressブロックにより閲覧できず、診断は未実施。
  → Claude on Chrome で本人環境から確認するか、内容を共有してもらう。

## 3. 本人提案の評価（いずれも不採用）

### 3.1 ホームページ作成・営業 → ✕ 不採用

| 観点 | 評価 |
|---|---|
| 営業力の活用 | ◎ 100%効く |
| Claude の活用 | ◎ 制作を丸ごと担える |
| **副業規定** | **✕ 致命的。** 勤務先は法人向けWeb・ITソリューションを提供しており、**最も競合認定リスクが高い** |
| 市場性 | ✕ STUDIO/ペライチ/Wixで自作可能。AIで価格崩壊中。単発制作はコモディティ化 |
| 説得力 | ✕ **本人が自分のサイトで集客に失敗している。**「集客できるサイトを作ります」と言えない |

→ 噛み合わせ自体は良いが、**副業規定リスクが致命的。不採用。**

### 3.2 無在庫物販 → ✕ 不採用

| 問題 | 内容 |
|---|---|
| **規約リスク** | メルカリは手元にない商品の出品を禁止。Amazonも実質制限。無在庫が公認なのはBUYMA程度。**アカウント停止＝事業消滅** |
| **30分/日と衝突** | 受注後の仕入れ、配送遅延の連絡、返品・クレーム対応が**すべて相手の都合で発生する**。営業メールを却下したのと同じ構造 |
| **利益率** | 5〜15%。月**利益**3〜5万なら**月商30〜100万円**が必要。仕入れ資金が先に出るため予算月1〜3万と矛盾 |
| **Claude が代われない** | リサーチと商品説明文は書けるが、仕入れ・検品・発送・顧客対応・アカウント管理は代替不可。**本人の時間が直接削られる** |

→ **「Claudeに任せて30分/日」という本計画の根本と、物販は相性が最悪。不採用。**

## 5. 推奨する組み合わせ

### 5.1 第1候補：提案書・営業資料の作成代行（#1）

**本人の条件に最もきれいに噛み合う。**

| 条件 | 評価 |
|---|---|
| オンライン実名NG | ○ ニックネーム表示で販売できる |
| IT系競合NG | ○ **IT領域ではない** |
| 商談時間が限られる | ○ **商談ゼロ。テキストで完結** |
| コードが書けない | ○ 不要 |
| Claude の活用 | ◎ 構成・文章・図解をすべて生成できる |
| 差別化 | ◎ **「大手法人営業の型」は経験者しか書けない** |
| **FPとの決定的な違い** | ◎ **実務経験がある。** ここが最大の差 |

- 想定顧客: 提案書が書けずに困っている中小企業の営業担当、個人事業主、フリーランス
- 単価1〜5万 → **月1〜3件で目標達成**
- 初収益まで **1〜2ヶ月**

### 5.2 第2候補：補助金・助成金の申請支援（#6）

**単価が最も高く、月1件で目標に届く。** 補助金50万円の成功報酬10〜15%で5〜7万円。
書類のドラフトは Claude が全て書ける。

> ⚠️ **法的な線引きが必須**
> 申請書類の「作成代行」は行政書士の独占業務に触れるおそれがある。
> **「助言・添削・情報提供」に留める**か、認定支援機関と組む形にする。
> また **IT導入補助金は対象外**とする（IT系のため）。

### 5.3 第3候補：営業代行（非IT商材）（#2）

**本人の営業力が100%発揮される唯一の案。** 平日夜20〜21時と土日の商談枠がそのまま活きる。
非IT商材（食品、設備、地域サービス、士業など）に限定すれば副業規定も安全。

- 障害は **「売る商材を見つける」** の一点。リスト作成は Claude が担えるが、最初の1社は人の縁になる。

### 5.4 裏で回すもの：営業テンプレート販売（#8）

**Claude が単独で作り続ける。本人の30分を消費しない。**
第1候補の納品物が、そのままテンプレート商品の原型になる。

> **稼ぎながら在庫が積み上がる構造。** #1 で受けた実案件 → 汎用化 → #8 の商品に転用。

| やってよい | やってはいけない |

| 営業活動の代行（非IT商材） | **IT・Web商材の営業**（副業規定に抵触） |

## 7. 撤退基準

- **M3終了時**: 受注0件 → 商品設計・価格・出品先を全面見直し
- **M6終了時**: 収益0円 → 案を入れ替える
- **月額コストが収益を3ヶ月連続で上回る** → 規模を縮小
- **副業規定への抵触が少しでも疑われた時点** → その案は即時中止（本業が最優先）

## 8. 運用体制

### Claude が自動でやること（本人の承認なし）

- 提案書・資料・テンプレートの作成、リサーチ、文章生成
- 出品文・商品説明の草案作成
- 市場調査（競合、価格帯、需要）
- 進捗のGitコミットと日次レポート

### 必ず本人の承認を取ること

- 課金が発生する操作すべて
- 外部サービスへのアカウント登録、出品、外部への公開・発信
- **顧客への納品物の最終確認と、回答内容**（代行業は本人の責任で行う）
- 副業規定に触れる可能性がある一切の判断

### 本人の30分/日の使い方

- 15分: Claude の日次レポートを読み、方向を判断する
- 15分: 納品物のレビュー（**営業経験者としての品質判断は本人以外にできない**）

### 商談枠（平日夜20〜21時／土日、月2〜4回）

- 第1候補（#1）: **商談不要**
- 第3候補（#2 営業代行）: 解禁後の商談に充てる

## 9. 必要なツール

本人はツールに詳しくないため、**触るものを最小限に絞る。**

| # | やること | 費用 | 所要 | 時期 |
|---|---|---|---|---|
| 1 | 事業用Googleアカウントを1つ作る | 無料 | 10分 | 今すぐ |

### 使わないもの

| 不採用 | 理由 |
|---|---|
| メール配信ツール | 営業メールをやらないため不要 |
| Stripe等の決済 | プラットフォーム経由のため不要 |

> 住民税額の変化から**勤務先に副収入が伝わる。**
