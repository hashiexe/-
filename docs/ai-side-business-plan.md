### 1.1 「禁止事項B」の正確な意味

本人の意図は**「オンラインに実名を晒したくない」**であり、商談相手・契約書・請求書に実名が出ることは許容。

| 売り方 | 実名のオンライン公開 | 可否 |
|---|---|---|
| スキルマーケット（ココナラ等） | 不要（ニックネーム表示。本人確認は運営に対してのみ） | **○** |
| 1対1の商談 → 業務委託契約 | **不要**（通信販売ではないため特商法の対象外） | **○** |
| アフィリエイト / 広告収益 | 不要（自分が販売者ではないため） | **○** |
| Kindle / note / BOOTH | 不要（ペンネーム可） | **○** |
| 自サイト＋Stripe直販（BtoC通信販売） | 氏名の表示が原則 | **△** |

### 1.2 「禁止事項A」の再定義（第3版）

本人の判断により、副業規定を次のとおり運用する。

| 可否 | 内容 |
|:--:|---|
| **✕ NG** | **IT製品の提案・販売**（クラウド、SaaS、AI導入支援、システム提案など勤務先の商材と重なるもの） |

## 2. 第1版からの方針転換

### 2.1 FP軸を撤回した理由

1. **本人の意欲が続かない。** 飽きたものを半年続ける計画は、計画として成立しない。
2. **SEO上も不利だった。** 金融はGoogleがYMYL（人の財産に関わる領域）として最も厳しく評価する分野で、
   **個人・匿名・実務経験なし**という条件はSEOで最悪の組み合わせ。
   本人が既に `moneybase-fp.com` で集客に失敗しているのは、**能力ではなくジャンル選定の問題**である可能性が高い。
3. 第1版のA案（FPツール×アフィリエイト）は、この壁を「記事ではなくツールを作る」で回避する設計だったが、
   意欲の問題は回避できない。

→ **軸を「FP資格」から「エンタープライズ法人営業5年」に移す。**
   こちらの方が希少性が高く、実務経験があり、市場に明確な困りごとが存在する。

### 2.2 既存サイト `moneybase-fp.com` の扱い

- ドメイン名がFP縛りのため、他ジャンルへの転用は困難。**寝かせる。**
- ただし**「なぜ集客できなかったか」の分析には価値がある**（次に同じ失敗をしないため）。
- 現時点では Claude の実行環境からegressブロックにより閲覧できず、診断は未実施。
  → Claude on Chrome で本人環境から確認するか、内容を共有してもらう。

## 3. 本人提案の評価

### 3.1 ホームページ作成・営業 → ○ **解禁（第3版で判定を変更）**

第2版では副業規定を理由に不採用としたが、規定の再定義により**採用可能**となった。

| 観点 | 評価 |
|---|---|
| 営業力の活用 | ◎ 100%効く |
| Claude の活用 | ◎ 制作を丸ごと担える |
| 副業規定 | ○ **IT製品の提案ではないため可**（第3版の定義による） |
| 市場性 | △ 単発制作はAIで価格崩壊中。**月額運用をセットで売ることで単価を維持する** |
| 実績 | ✕ **本人が自分のサイトで集客に失敗しており、実績がない。**<br>→ 最初の1〜2件を知人に格安で制作し、実績として使う |

→ **第1候補に昇格。** ただし「制作のみ」では売らず、必ず**月額運用とセット**にする。

### 3.2 無在庫物販 → ✕ 不採用

| 問題 | 内容 |
|---|---|
| **規約リスク** | メルカリは手元にない商品の出品を禁止。Amazonも実質制限。無在庫が公認なのはBUYMA程度。**アカウント停止＝事業消滅** |
| **30分/日と衝突** | 受注後の仕入れ、配送遅延の連絡、返品・クレーム対応が**すべて相手の都合で発生する**。営業メールを却下したのと同じ構造 |
| **利益率** | 5〜15%。月**利益**3〜5万なら**月商30〜100万円**が必要。仕入れ資金が先に出るため予算月1〜3万と矛盾 |
| **Claude が代われない** | リサーチと商品説明文は書けるが、仕入れ・検品・発送・顧客対応・アカウント管理は代替不可。**本人の時間が直接削られる** |

→ **「Claudeに任せて30分/日」という本計画の根本と、物販は相性が最悪。不採用。**

## 5. 推奨する組み合わせ

### 5.1 第1候補：HP制作＋月額運用（#1）

単発制作はAIで価格崩壊中のため、**月額運用をセットで売る**ことで単価を維持する。

- **月1万円 × 3〜5社で目標達成**。しかもストック収入になる
- 本人が売り、Claude が作る。役割分担が最も明快
- **入口**: 実績がないため、最初の1〜2件は知人に格安で制作して実績にする
- 月額運用の中身: 更新代行、Googleビジネスプロフィール運用、簡単な改善

### 5.2 第2候補：求人票・採用ページ作成代行（#2）

中小企業は**人手不足で採用に予算が出る**一方、**求人票が書けない**。ここに明確な空白がある。

- Indeed・求人ボックスの原稿 ＋ 採用ページ制作で **単価3〜10万、月1件で目標達成**
- 競合が少なく、IT製品の提案にも当たらない
- **文章が中心のため Claude が最も活きる**

### 5.3 第3候補：補助金申請支援（#3）

**単価が最も高く、月1件で目標に届く。** 書類のドラフトは Claude が全て書ける。

> ⚠️ 申請書類の「作成代行」は行政書士の独占業務に触れるおそれがあるため、
> **「助言・添削・情報提供」に留める。**

### 5.4 裏で回すもの：営業テンプレート販売（#8）

Claude が単独で作り続ける。本人の30分を消費しない。実案件の成果物を汎用化して商品にする。

## 6. 相談業・代行業で越えてはいけない線

| やってよい | やってはいけない |
|---|---|
| 提案書・資料の作成、構成の助言 | — |
| 補助金制度の説明、申請書の**添削・助言** | **申請書類の作成代行**（行政書士法に抵触のおそれ） |
| 一般的な制度・税制の説明 | **個別の税額計算の代行**（税理士法に抵触のおそれ） |
| ホームページ制作、営業代行（非IT商材） | **IT製品の提案・販売**（副業規定に抵触） |

## 7. 撤退基準

- **M3終了時**: 受注0件 → 商品設計・価格・出品先を全面見直し
- **M6終了時**: 収益0円 → 案を入れ替える
- **月額コストが収益を3ヶ月連続で上回る** → 規模を縮小
- **副業規定への抵触が少しでも疑われた時点** → その案は即時中止（本業が最優先）

## 8. 運用体制

### Claude が自動でやること（本人の承認なし）

- 提案書・資料・テンプレートの作成、リサーチ、文章生成
- 出品文・商品説明の草案作成
- 市場調査（競合、価格帯、需要）
- 進捗のGitコミットと日次レポート

### 必ず本人の承認を取ること

- 課金が発生する操作すべて
- 外部サービスへのアカウント登録、出品、外部への公開・発信
- **顧客への納品物の最終確認と、回答内容**（代行業は本人の責任で行う）
- 副業規定に触れる可能性がある一切の判断

### 本人の30分/日の使い方

- 15分: Claude の日次レポートを読み、方向を判断する
- 15分: 納品物のレビュー（**営業経験者としての品質判断は本人以外にできない**）

### 商談枠（平日夜20〜21時／土日、月2〜4回）

- 第1候補（#1）: **商談不要**
- 第3候補（#2 営業代行）: 解禁後の商談に充てる
