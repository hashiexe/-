## 1. 前提条件（ここが全ての制約）

| 項目 | 内容 |
|---|---|
| **目標** | 月3〜5万円の副収入（半年〜9ヶ月以内） |
| **稼働** | 本人 30分/日 ＋ 商談枠 月2〜4回。**平日日中は本業のため不可。平日夜20〜21時 と 土日 が使える** |
| **予算** | 初期＋月額ランニングで 月1〜3万円 |
| **武器** | エンタープライズIT法人営業5年（ソフトバンク）／FP資格（知識のみ）／商談・提案力 |
| **弱点** | コードが書けない／発信チャネル（SNS・ブログ）を持っていない／**ツールに詳しくない** |
| **禁止事項A** | **IT系の競合になる副業はNG**（勤務先から明示） |
| **禁止事項B** | **オンライン（HP・SNS）での実名・顔出しはNG** |
| **実行部隊** | Claude（実装・リサーチ・文章・デプロイ・計測・日次レポート） |

### 1.1 「禁止事項B」の正確な意味

当初「匿名希望＝匿名でしか商売できない」と誤読したが、本人の意図は
**「オンラインに実名を晒したくない」**であり、商談相手・契約書・請求書に実名が出ることは許容。

この区別により、実務上の可否は次のとおり。

| 売り方 | 実名のオンライン公開 | 可否 |
|---|---|---|
| アフィリエイト / 広告収益 | 不要（自分が販売者ではないため特商法の表示義務の対象外） | **○** |
| Kindle / note / Gumroad / アプリストア | 不要（ペンネーム可。販売主体はプラットフォーム） | **○** |
| 自サイト＋Stripe直販（BtoC通信販売） | 氏名の表示が原則。住所はバーチャルオフィスで代替可 | **△** |
| 1対1の商談 → 業務委託契約（BtoB受託・顧問） | **不要**（通信販売ではないため特商法の対象外。契約書・請求書に本名が載るだけ） | **○** |

→ **受託・顧問型は禁止事項Bを一切侵さない。** 塞いでいるのは禁止事項A（副業規定）だけ。

### 1.2 「禁止事項A」が潰す範囲

勤務先は法人向けにクラウド・SaaS再販・AI導入支援・SIまで手がけるため、
**「AIやITを法人に売る」領域は広範に競合認定のリスクがある。**

- AI導入支援・業務自動化代行（法人向け） → **リスク大**
- 法人向けSaaS・受託開発 → **リスク大**
- 個人向け（BtoC）のWebツール・コンテンツ → **リスク小**
- 非IT領域（金融知識の提供など） → **リスクほぼなし**

月3〜5万円と本業を天秤にかけた場合、グレーゾーンを攻める合理性はない。
**副業規定の正確な範囲を確認するまで、法人向けIT領域には一切手を出さない。**

### 2.1 採用しなかった収益モデルと理由

| モデル | 却下理由 |
|---|---|
| 自社サブスク（Stripe直課金） | 特商法により氏名の表示が原則必要。禁止事項Bと衝突 |
| AdSense広告のみ | 月3〜5万に月10〜30万PVが必要。単価が低すぎる |
| クラウドソーシング（ランサーズ等） | 時間単価が低く、30分/日の制約と合わない |
| 買い切り販売（note/Gumroad単体） | 結局こちらで集客が必要になり、Sの上位互換にならない |

### 2.2 結論

**S を即日着手、A を Claude が裏で育成、B は副業規定の確認が取れ次第 解禁。**

理由:

- **S は副業規定の確認を待たずに始められ、初収益が最速（1〜2ヶ月）。**
  プラットフォームが集客を担うため、「発信チャネルを持っていない」という最大の弱点を回避できる。
  他のFPがExcelで手作業しているライフプラン表を、Claude が精度と速度で上回れる点が差別化軸。
  実務経験がない弱点は、納品物の質で埋める。
- **B が最高効率**（顧客1社で目標達成、営業力が100%効く）だが、副業規定の確認が着手条件。
  平日夜が使えることが確定したため、障害は副業規定のみになった。
- **A は最も遅いが、唯一の完全ストック型。** 一度上位表示されれば稼働ゼロで収益が続く。
  実装・調査・計測をすべて Claude が担うため、本人の30分を消費しない。

**3案は相乗する。**

> S で実際に相談された「生の悩み」 → A のツール企画に転用 → SEOで流入 → S へ誘導

顧客の悩みがそのままツールの企画書になる。S で稼ぎながら A の資産を積む構造。

### 2.3 相談業で越えてはいけない線（必ず遵守）

| やってよい | やってはいけない |
|---|---|
| ライフプラン表の作成、家計診断 | **個別の投資商品・銘柄の推奨**（金融商品取引業の登録が必要） |
| 住宅ローン・教育資金のシミュレーション | **保険商品の募集・勧誘**（保険募集人の登録が必要） |
| 税制・社会保険の一般的な制度説明 | **個別の税額計算の代行**（税理士法に抵触のおそれ） |

原則: **「計算して見せる」「制度を説明する」はよい。「この商品を買え」は違法。**
サービス説明文にこの線引きを明記して自衛する。A案のツール上の表記も同じ原則に従う。

## 4. 資産A：FP × 金融ツール × アフィリエイト（Claude が裏で育成）

### 4.1 なぜこの組み合わせか

1. **FP資格はIT競合規定に全く触れない。** 禁止事項Aを完全に回避できる唯一の武器。
2. **アフィリエイトは特商法の表示義務の対象外。** 禁止事項Bを完全に回避できる。
3. **金融アフィリの単価が異常に高い。**
   - 証券口座開設: 1件 1〜2万円
   - クレジットカード発行: 1件 1万円前後
   - 住宅ローン比較・借換え: 1件 2〜3万円
   - → **目標の月3〜5万円 ＝ 成約 月3〜5件。**
     AdSense型なら月10〜30万PVが必要なところ、**月3,000〜1万PVで届く。**
4. **コードを書くのは Claude。** 本人の弱点が弱点にならない。

### 4.2 最大のリスクと、その回避策

**リスク: 金融は Google が YMYL（人の財産に関わる領域）として最も厳しく評価するジャンルであり、
匿名個人の「解説記事」は検索でまず上位に上がらない。**

これは事実であり、金融アフィリで個人が失敗する最大の原因。

**回避策: 「記事を書く」のではなく「計算ツールを作る」側に全振りする。**

- 計算ツール（シミュレーター）は解説記事ほどYMYL評価の影響を受けにくい
- 「使える道具」は自然な被リンク・SNS拡散が発生しやすい
- **既存の無料シミュレーターは前提条件が雑なものが多く、FP知識で差別化できる**
  （例: 住宅ローン控除・団信・繰上返済のタイミングを織り込んでいない等）
- ここが本人のFP知識と Claude の実装力が噛み合う一点

### 4.3 ツール候補（初期3〜5本）

| # | ツール | 差別化の軸 | 想定収益導線 | 単価 |
|---|---|---|---|---|
| 1 | 住宅ローン 繰上返済シミュレーター | 期間短縮型 vs 返済額軽減型を、**住宅ローン控除と団信を織り込んで**比較 | 住宅ローン借換え比較 | 高 |
| 2 | 新NISA 出口戦略シミュレーター | 積立ではなく**取り崩し**に特化。取り崩し順序・暴落時の挙動 | ネット証券 口座開設 | 高 |
| 3 | 退職金 一時金 vs 年金 比較 | 税＋社会保険料まで込みの手取り比較 | 保険相談・証券 | 高 |
| 4 | iDeCo 受取シミュレーター | 退職所得控除の通算ルールを踏まえた受取時期の最適化 | iDeCo口座 | 中 |
| 5 | 年収の壁 手取り計算機 | **制度改正が頻繁なため、更新頻度で勝てる**（最新の控除額は要確認） | AdSense＋保険相談 | 低・PV型 |

※ 税制・社会保険の数値は改正が多い。**実装前に Claude が一次情報（国税庁・厚労省・金融庁）で確認し、
本人がFPとして妥当性を検証する。** 計算ロジックの正しさがこの事業の唯一の資産。

## 5. 本命B：非IT領域の顧問・受託（副業規定の確認が前提）

**着手条件: 勤務先の副業規定を確認し、対象領域が競合に当たらないことを確認できた場合のみ。**

- ターゲット: 飲食・小売・士業・地域の小規模事業者など、**勤務先が法人営業で相手にしない規模**
- 入口: 紹介のみ。コールドメール・広告は使わない（30分/日と最も相性が悪い）
- 商談: 月2〜4回の枠を使う。**本人の営業力が100%効く唯一の案**
- 作業: 実装・資料作成・調査はすべて Claude が担当
- 収益: 月額顧問3〜5万円 × 1社で目標達成
- **月3〜5万円なら顧客1社で足りる。** SaaSなら有料ユーザー30〜100人が必要な水準

### 5.1 商談可能時間の確定（解決済み）

当初は土日のみと想定していたが、**平日夜20〜21時のZoomが月2〜4回取れる**ことが確定した。
これによりB案の最大の障害が解消された。

| 相手 | 土日 | 平日夜20〜21時 |
|---|---|---|
| 飲食・小売・美容 | 最繁忙で不可 | **閉店後で最も話を聞ける時間帯。◎** |
| 士業・BtoB企業 | 休みで捕まらない | △ |
| 個人事業主・フリーランス | ○ | ○ |

→ **飲食・小売がターゲットに戻り、B案は目標額と噛み合う。**
   残る着手条件は副業規定の確認のみ。

## 8. 運用体制（誰が何をするか）

### Claude が自動でやること（本人の承認なし）

- コードの実装・修正、Vercelへのデプロイ
- 一次情報（国税庁・金融庁等）のリサーチと、計算ロジックの根拠整理
- 記事・ツール説明文の執筆
- GA4 / Search Console の数値取得と日次レポートのリポジトリ追記
- 進捗のGitコミット

### 必ず本人の承認を取ること

- ドメイン購入・課金の発生する操作すべて
- ASPへの申請、外部サービスへのアカウント登録
- SNSアカウントの作成・投稿など、**外部への公開・発信**
- 計算ロジックの確定（**FPとしての検証は本人以外にできない**）
- スキルマーケットへの出品内容・価格の決定、および納品物の最終確認
- **顧客への回答・アドバイスの内容**（相談業は本人の責任で行う）
- 副業規定に触れる可能性がある一切の判断

### 本人の30分/日の使い方

- 15分: Claudeの日次レポートを読み、方向を判断する
- 15分: S案の納品物のレビュー、または A案の計算ロジックをFPとして検証する

**商談枠（平日夜20〜21時／土日、月2〜4回）**
- S案: 相談者とのやり取り（多くはテキストで完結）
- B案: 解禁後の商談に充てる
- A案: **商談は一切発生しない**

### Claude on Chrome の役割

APIのない管理画面（Search Console、ASP管理画面、ドメイン管理）の操作を、
**本人の30分の中で、監督下で**行う。無人の常時稼働インフラとしては使わない
（本人のPCとChromeが起動している間しか動かないため）。

## 9. 意図的に採用しなかった案と、その理由

| 不採用案 | 理由 |
|---|---|
| 新規Googleアカウントからの営業メール一括送信 | 新規アカウントのコールドメールは数十通で迷惑メール判定、100通規模で凍結が通例。独自ドメイン＋SPF/DKIM/DMARC＋数週間のウォームアップが必須で、それ自体が事業になる。加えて**返信対応は相手の都合で発生するため、30分/日の枠に収まらない** |
| 法人向けAI導入支援・業務自動化代行 | **副業規定（IT系競合NG）に真っ向から抵触** |
| 法人向けSaaSの自社開発 | 同上。加えて有料ユーザー30〜100人が必要で、月3〜5万に対して過剰な難度 |
| BtoC向けSaaS（自社課金） | 特商法により氏名の表示が原則必要となり、禁止事項Bと衝突 |
| 金融分野の「解説記事」中心のSEOメディア | YMYL評価により、匿名個人サイトは検索上位を取れない |

### 10.1 本人がやること（これだけ）

| # | やること | 費用 | 所要 | 時期 |

### 10.2 各ツールの役割

| ツール | 役割 | 費用 |
|---|---|---|
| **Vercel** | 作ったサイトを公開する場所 | 無料 |
| **Google Search Console** | 何の言葉で検索され、何位に出て、何人が押したかを見る。**この事業の生命線** | 無料 |

### 10.3 ドメインの取得先

| サービス | 評価 |

| **ムームードメイン** | **推奨。** 日本語で分かりやすく、Whois代理公開が無料 |

### 10.4 ASP（登録順）

| ASP | 特徴 | 時期 |
|---|---|---|
| **A8.net** | 国内最大手。**サイトが無くても登録可**なので先に済ませられる。金融案件が豊富 | 最初 |
| **もしもアフィリエイト** | 初心者向け。報酬に+12%上乗せの仕組みあり | 次 |
| アクセストレード | 金融・証券に強い | サイトが育ってから |
| バリューコマース | 証券に強いが審査がやや厳しい | 同上 |

登録には本名・住所・振込先口座が必要だが、**ASPに対してのみ**であり、サイト上には出ない。匿名は保たれる。

### 10.5 収益が出てから（それまで不要）

- **freee / マネーフォワード クラウド確定申告** … 年1万円程度。年間所得20万円超から

> ⚠️ **最重要の実務ポイント**
> 確定申告で**住民税を「自分で納付（普通徴収）」**に選ばないと、
> 住民税額の変化から**勤務先に副収入が伝わる。** チェック1つだが、忘れると副業規定の問題が現実化する。

### 10.6 あえて使わないもの

| 不採用 | 理由 |
|---|---|
| メール配信ツール（Instantly等） | 営業メールをやらないため不要 |
| Stripe等の決済サービス | アフィリエイトのため自分で決済を持たない |
| Supabase | 計算ツールは静的サイトで足りる。DB不要（とろりロードとは設計が異なる） |
| WordPress・レンタルサーバー | Vercelなら無料。月1,000円前後の固定費が不要になる |
| SNS運用ツール | 発信チャネルが無い以上まずSEO一本。道具を増やすほど30分が削られる |

### 10.7 Claude 側が使うもの（本人の操作は不要）

Claude Code（実装）／定期トリガーによる自動起動／Web検索での一次情報調査／Git・GitHub／Vercelへのデプロイ。

**Claude on Chrome の使いどころ**: 10.1 の1〜5はいずれもAPIが無くブラウザ操作が必要。
ここで Claude on Chrome が画面を操作し、**本人は見て承認するだけ**にできる。土日または平日夜にまとめて処理するのが効率的。
