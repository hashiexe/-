# 営業トップページ 修正仕様書

作成: 2026-09-18 / 対象: `hashiexe/hp-biz` の `index.html`
実装担当: Claude Sonnet（新規セッション） / 設計: Claude Opus

---

## 0. 背景

公開済みの営業トップ（https://hashiexe.github.io/hp-biz/ ）を検証した結果、
**営業ページとして必須の要素が欠落している。**

| 欠落 | 影響 |
|---|---|
| **問い合わせ導線が一切ない** | **見た人が連絡できない。営業ページとして機能しない** |
| 料金の記載がない | 初期3万＋月1.5万という最大の武器が伝わらない |
| WordPressとの比較がない | 「サーバー代0円」という営業トークの核が伝わらない |
| 制作の流れがない | 発注後のイメージが湧かず、問い合わせの心理的ハードルが残る |
| FAQ がない | 「写真がない」「パソコンが苦手」という典型的な不安が解消されない |

現状で残っている「整体院特化」「広告規制対応」「スマホ優先」「症状別ページ」の訴求と
制作事例へのリンクは**そのまま活かす**。不足分を足す修正とする。

## 1. この修正のゴール

**サンプルを見て良いと思った人が、その場で連絡できる状態にすること。**

判断に迷ったら「問い合わせが増えるか」で決める。

## 3. 料金プラン（3プラン横並び。サブスクを推奨として強調）

| プラン | 初期 | 月額 | 内容 |
|---|---|---|---|
| ライト | 80,000円 | 5,000円 | 1ページ／スマホ対応／地図／問い合わせフォーム／月1回まで更新 |
| **サブスク（推奨）** | **30,000円** | **15,000円**（12ヶ月〜） | 5ページ／**更新回数無制限**／予約フォーム／Googleビジネスプロフィール運用／**症状別ページを毎月1本追加**／月次レポート |
| 買い切り | 150,000円 | 10,000円（任意） | 5ページ／保守は任意 |

- サブスクのカードに「いちばん選ばれています」バッジを付け、枠線で強調する
- 表示価格はすべて税込である旨を注記
- ドメイン代（年1,500円前後）のみ実費負担である旨を注記
- **「症状別ページを毎月1本追加」は月額の価値を説明する要。必ず入れる**

## 4. WordPressとの違い（比較表）

| | 当方 | 一般的なWordPress |
|---|---|---|
| サーバー代 | **0円** | 月1,000円前後 |
| 表示の速さ | 速い | やや遅い |
| 乗っ取り・改ざん | 構造上ほぼ起きない | 対策が必要 |
| プラグイン更新 | 不要 | 定期的に必要 |
| 更新作業 | ご連絡いただければ当方が対応 | ご自身で操作 |
| スマホ対応 | 標準 | テーマ次第 |

当方側は緑、WordPress側は赤系の色で差を視覚化する。
表の下に「年間約12,000円のサーバー代が不要になります」と一行添える。

## 5. よくあるご質問（アコーディオン）

1. 写真や文章がないのですが、大丈夫でしょうか
2. パソコンが苦手でも更新できますか
3. 途中でやめることはできますか
4. ドメイン（独自のURL）はどうなりますか
5. 今あるホームページを作り直すこともできますか
6. **サイトを買い取ることはできますか** ← 囲い込みへの不安を消す。12ヶ月経過後20〜30万円＋譲渡手数料3〜5万円、microCMSで編集できる状態で引き渡す旨を書く

回答は各150字程度。断定を避けず、はっきり答える。

## 6. お問い合わせ（最重要・必須）

**このセクションが無いことが現状の最大の問題。必ず実装する。**

| 項目 | 指定 |
|---|---|
| 見出し | 「まずは、お話を聞かせてください」 |
| リード | 「ご相談とお見積りは無料です。その場で契約をお願いすることはありません。」 |
| 手段1 | **メールリンク**（`mailto:`）。アドレスは `CONTACT_EMAIL_PLACEHOLDER` と書いておき、本人が差し替える |
| 手段2 | **問い合わせフォーム**（名前／メール／院名／ご相談内容の4項目） |
| フォーム送信先 | Formspree を想定。`action="https://formspree.io/f/FORM_ID_PLACEHOLDER"` とし、本人がIDを差し替える |
| 配置 | ページ下部に加え、**ヘッダーのボタンとファーストビューのボタンからもここへアンカーリンク** |

> **実装注記**: GitHub Pages は静的ホスティングのためサーバー側でフォーム送信を処理できない。
> Formspree（無料枠あり）の action URL を使うか、当面は `mailto:` リンクのみでも機能する。
> **プレースホルダのまま公開しないよう、本人への申し送りを README に書くこと。**

## 7. 屋号の扱い

現在の仮称は「あおい制作所」。**本人が屋号を決めるまでは `SHOP_NAME_PLACEHOLDER` と書かず、
「あおい制作所」のまま実装してよい**（後で一括置換できるよう、屋号は1箇所のCSS変数ではなくテキストとして素直に書く）。

## 8. 技術・デザイン仕様

| 項目 | 指定 |
|---|---|
| 既存スタイル | **現在の `index.html` のカラー（`--color-primary: #1c7a84` 等）とトーンを維持する** |
| ファイル構成 | `index.html` 単体（CSSは現状どおり `<style>` 内に記述） |
| 外部ライブラリ | 使わない |
| レスポンシブ | 360px幅で横スクロールが出ないこと |
| 本文サイズ | 16px以上 |
| リンク | **すべて相対パス**（GitHub Pages のサブディレクトリ配信で絶対パスは壊れる） |
| アコーディオン | `<details>` / `<summary>` を使う（JS不要） |
