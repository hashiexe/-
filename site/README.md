# お芋やとろり 公式サイト

対面でお会いしたお客さまの **リピート購入** を受け止めるための小さなサイトです。
新規集客（SEO）は狙わず、決済手数料の安さと運用のラクさを最優先にしています。

```
site/
├─ index.html               骨組み（基本さわらない）
├─ styles.css                デザイン（色は先頭の :root で変えられます）
├─ main.js                   表示の組み立て（基本さわらない）
├─ content.js                ★ 文言はここ ★（年に数回だけ触ります）
├─ SPREADSHEET_SETUP.md      出店スケジュールの設定手順
├─ favicon.svg               タブのアイコン
└─ assets/                   写真を置く場所
```

**ふだんの運用で編集する場所は2つだけです。コードは触りません。**

| 情報 | 更新頻度 | 編集する場所 |
|---|---|---|
| 出店スケジュール | 毎週〜隔週 | **Googleスプレッドシート**（→ [SPREADSHEET_SETUP.md](./SPREADSHEET_SETUP.md)） |
| 商品・価格・在庫・売り切れ | 月数回 | **Squareの管理画面**（ダッシュボード → オンラインビジネス） |
| とろりについて／オーナー情報など | 年に数回 | `content.js`（開発者が対応） |

---

## 1. まず見てみる

`site/index.html` をダブルクリックするだけでブラウザに表示されます（ビルド不要）。

---

## 2. 出店スケジュールの更新（スプレッドシート）

手順は [SPREADSHEET_SETUP.md](./SPREADSHEET_SETUP.md) にまとめています。
設定が済んだあとは、シートに行を1つ足すだけで数分以内にサイトへ反映されます。**過ぎた日付は自動で消え**、直近の予定には自動で **NEXT** の印が付きます。

シートが読み込めない場合（通信エラー等）は、`content.js` の `scheduleSection.events` に書かれたバックアップ内容がそのまま表示されるので、画面が空になることはありません。

---

## 3. 商品の更新（Square）

商品名・価格・写真・在庫・売り切れは、**すべてSquareのオンラインビジネス管理画面で管理します**。サイト側（`content.js`）を編集する必要はありません。

1. Square ダッシュボード → **オンラインビジネス** で商品を追加・編集
2. 保存すると、サイトの「Squareショップで見る・購入する」ボタンの先（Squareストア）に自動反映されます

サイトの「ネット販売」セクションは常設のご案内文＋ボタン1つだけの構成です。商品を増やしても、値上げしても、売り切れにしても、**サイト側は二度と触りません**。

初めてSquareストアを作るときだけ、発行されたストアURL（例: `https://oimoyatorori.square.site`）を `content.js` の `links.shopTop` に貼ってください（この1回だけコードを触ります）。

---

## 4. 写真の入れ方

`site/assets/` に **決まった名前** で置くだけで、プレースホルダが自動で写真に差し替わります。

| ファイル名          | 使われる場所            | 推奨サイズ |
| -------------------- | ----------------------- | ---------- |
| `assets/hero.jpg`    | トップの大きな写真      | 1200×1200  |
| `assets/about.jpg`   | とろりについて          | 900×1200   |
| `assets/shop.jpg`    | ネット販売（Squareへの案内） | 1000×800   |
| `assets/owner.jpg`   | つくっている人          | 800×800    |
| `assets/ogp.jpg`     | LINE/SNSで共有された時  | 1200×630   |

写真は 1 枚 300KB 以下を目安に圧縮してください（[squoosh.app](https://squoosh.app) が手軽です）。
**この店のいちばんの武器は「割ったときの蜜の断面」写真です。ここだけは妥協しないでください。**

---

## 5. 公開する（Vercel）

このリポジトリを Vercel に接続し、プロジェクト設定で

- **Root Directory**: `site`
- **Framework Preset**: `Other`（ビルドコマンドなし）

を指定すれば、`git push` するたびに自動で公開されます。

独自ドメインは Vercel の Domains から追加します（ドメイン自体は Cloudflare Registrar が原価に近く安いです。`.com` で年 1,500 円ほど）。
