# お芋やとろり 公式サイト

対面でお会いしたお客さまの **リピート購入** を受け止めるための小さなサイトです。
新規集客（SEO）は狙わず、決済手数料の安さと運用のラクさを最優先にしています。

```
site/
├─ index.html    骨組み（基本さわらない）
├─ styles.css    デザイン（色は先頭の :root で変えられます）
├─ main.js       表示の組み立て（基本さわらない）
├─ content.js    ★ 文言・商品・出店予定はぜんぶここ ★
├─ favicon.svg   タブのアイコン
└─ assets/       写真を置く場所
```

---

## 1. まず見てみる

`site/index.html` をダブルクリックするだけでブラウザに表示されます（ビルド不要）。

---

## 2. ふだんの更新は `content.js` だけ

### 出店予定を足す

`scheduleSection.events` に 1 ブロック足すだけです。**過ぎた日付は自動で消えます。**

```js
{
  date: '2026-09-13',        // かならず YYYY-MM-DD
  place: 'イケ・サンパーク',
  area: '東京都豊島区',
  time: '10:00 – 16:00',
  note: '南口テント付近です',
},
```

いちばん近い予定は自動で **NEXT** バッジが付き、トップにも表示されます。

### 商品を足す・売り切りにする

`shopSection.products` の `url` に Square の決済リンクを貼ります。
`url: ''`（空）にしておくと、そのカードは自動で **「準備中」** 表示になります。売り切れのときはここを空にするのがいちばん速いです。

---

## 3. 写真の入れ方

`site/assets/` に **決まった名前** で置くだけで、プレースホルダが自動で写真に差し替わります。

| ファイル名                 | 使われる場所            | 推奨サイズ    |
| -------------------------- | ----------------------- | ------------- |
| `assets/hero.jpg`          | トップの大きな写真      | 1200×1200 |
| `assets/about.jpg`         | とろりについて          | 900×1200  |
| `assets/owner.jpg`         | つくっている人          | 800×800   |
| `assets/product-1.jpg` …   | 商品カード（上から順）  | 1000×800  |
| `assets/ogp.jpg`           | LINE/SNSで共有された時  | 1200×630  |

写真は 1 枚 300KB 以下を目安に圧縮してください（[squoosh.app](https://squoosh.app) が手軽です）。
**この店のいちばんの武器は「割ったときの蜜の断面」写真です。ここだけは妥協しないでください。**

---

## 4. Square の決済リンクの作り方

1. Square ダッシュボード → **オンラインチェックアウト** → 決済リンクを作成
2. 「商品を販売する」を選び、商品名・価格・写真・在庫数を設定
3. **配送先住所の収集をON**、送料を設定（全国一律 or 地域別）
4. 発行された URL をコピー
5. `content.js` の該当商品の `url` に貼る

これでカート・在庫・領収書・カード情報の保護はすべて Square 側が担当します。
**自前でカートを作らないのが、安全でいちばん安い方法です。**

---

## 5. 公開する（Vercel）

このリポジトリを Vercel に接続し、プロジェクト設定で

- **Root Directory**: `site`
- **Framework Preset**: `Other`（ビルドコマンドなし）

を指定すれば、`git push` するたびに自動で公開されます。

独自ドメインは Vercel の Domains から追加します（ドメイン自体は Cloudflare Registrar が原価に近く安いです。`.com` で年 1,500 円ほど）。
